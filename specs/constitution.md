Create a constitution for an AI Knowledge Workspace project.

Project Vision:
Build an AI-powered personal knowledge system where users can upload documents, organize knowledge, perform semantic search, and interact with documents using Retrieval-Augmented Generation (RAG).

Core Principles:
1. Knowledge-first, chat-second.
2. Retrieval must be explainable through citations.
3. AI augments learning rather than replacing it.
4. Every feature must solve a real user problem.
5. Backend quality is prioritized over UI polish.
6. Every technology choice must be explainable.
7. Frameworks are replaceable; concepts are not.
8. Measure retrieval quality over feature count.
9. Design for future scalability.
10. Build incrementally through milestones.
11. Production-minded engineering.
12. Learn through implementation and debugging.

Technical Constraints:
- FastAPI backend
- PostgreSQL
- ChromaDB
- Next.js frontend
- Docker deployment
